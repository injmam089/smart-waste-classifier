        About Smart Waste Classifier

        The Smart Waste Classifier is a mobile-first Progressive Web App designed to promote sustainable waste sorting using client-side machine learning.

        🔬 Visual Feature Analysis Notice

        This application analyzes visual features (color, shape, contours, edges, and textures) using a trained image classification model. It does not physically measure weight, exact material purity, or dimensions. Confidence percentages represent statistical model probability based on training data.

        🔒 Privacy & Data Handling

        Camera input is processed completely on your device. The app does not upload captured images or video feeds to any remote server. Only anonymous classification metadata (category, timestamp, confidence) is saved locally in your browser's LocalStorage.
